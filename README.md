## 填寫資料
### 開啟檔案
* 打開Python IDLE
* 點擊`File` -> `Open...`
### 基本資料填寫(參考填寫資料頁面)
* 在line 17 ' '內填寫學校區域 EX:中正區
* 在line 18 ' '內填寫學校級別 EX:高中
* 在line 19 ' '內填寫學校名稱 EX:市立成功高級中學
* 在line 20 ' '內填寫年級 
* 在line 21 ' '內填寫班級
* 在line 23 ' '內填寫姓名及座號 EX: 40王小明
* 在line 24 ' '內填寫語言代號(可跳過)
# 執行
## 執行步驟
* 點擊`Run` -> `Run Module`
### 執行完畢後確認輸出為 `outok=1` 並在排行榜找到自己的資料及為成功
